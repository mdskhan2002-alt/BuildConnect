# BuildConnect

BuildConnect is a responsive frontend starter for a real-estate and construction ecosystem marketplace.

## Included
- Landing page
- Marketplace cards
- Category filters
- Search
- Requirement posting modal
- Login/signup demo modals
- Contact/enquiry flow
- Stakeholder network section
- Responsive mobile layout

## Run
Open `index.html` in a browser.
